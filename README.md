## 这是什么

这是课程作业-2，研究对象与作业-1 相同：**小鹏汇天「陆地航母」分体式飞行汽车（飞行体 X3-F）**，但分析视角从“技术/场景/市场可行性”切换为**系统安全工程**。

网站回答四个问题：

1. **有哪些危害？** 失控、推力丧失、电池热失控、空中相撞、障碍物、分合误锁、高压电击、地面车辆、人为因素、坠后火灾、网络攻击。
2. **风险有多大？** 用后果 × 可能性的定性矩阵，结合 FTA / FMEA / 共因分析，识别单点与共因路径。
3. **屏障是否可信？** 从预防、检测、恢复、逃生、救援五层检查；强调“冗余 ≠ 独立”“有要求 ≠ 有证据”。
4. **安全案例是否闭合？** 用 STPA、GSN、SMS 与适航证据表，判断公开证据能支持到什么程度。

结论是：**安全设计意图可信，但公开安全证据不足；当前适合在严格限制下的受控示范、私人娱乐与飞行培训中积累证据，不适合作为商业载人运输的“已证明安全”产品。**

### 方式 A：网页上传

1. 登录 GitHub，创建 **Public** 仓库，例如 `flying-car-x3f-safety`。
2. 进入空仓库，选择 **uploading an existing file**。
3. 上传本目录**全部内容**到仓库根目录，确保：
   - `index.html` 在根目录，不在子文件夹里；
   - `assets/` 与 `index.html` 同级。
4. Commit changes。
5. **Settings → Pages**：
   - Source: **Deploy from a branch**
   - Branch: **main**，目录 **/ (root)**
   - Save
6. 1–3 分钟后访问：
   - `https://<用户名>.github.io/flying-car-x3f-safety/`


之后按方式 A 的第 5–6 步开启 Pages。

## 主要证据

- **CAAC《X3-F 型航空器专用条件征求意见稿》**：X3.561 应急着陆载荷、X3.612 折叠锁止、X3.1308 HIRF、X3.1329 自动驾驶、X3.1331 飞控、X3.1353 电池、X3.1433 电缆、X3.1505 VNE。
- **ARIDGE / 小鹏汇天官方产品页**：6×6、800V 增程、六旋翼双涵道、折叠收纳。
- **中创新航（CALB）**：360 Wh/kg、25C 放电。
- **标准**：ARP4754A/4761A、DO-178C/DO-254、ISO 26262/21448/34502、ICAO Doc 9859、STPA Handbook、GSN、DO-326A/356A。
- 完整 23 条来源见网站第 13 节。

关键数据均标注证据等级；企业口径、监管要求与本报告判断分开呈现。公开材料没有 FHA/PSSA/SSA、软件保证、电池热传播、分合 HIL 或机队数据——这些缺口本身就是结论的一部分。
